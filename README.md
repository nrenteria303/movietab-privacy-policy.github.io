# MovieTab Privacy Policy

Last Updated: June 2026

MovieTab is a Chrome extension that replaces the browser's new tab page with movie information sourced from The Movie Database (TMDB).

## Data Collection

MovieTab does not collect, store, transmit, or sell any personal information.

MovieTab does not collect:

- Browsing history
- Search history
- Personal identifiers
- Account information
- Location information
- User-generated content

## Third-Party Services

Movie information is retrieved through a backend service hosted on Netlify, which in turn accesses data from The Movie Database (TMDB).

These requests are used solely to retrieve movie information displayed in the extension.

## Data Sharing

MovieTab does not share user information with any third parties.

## Contact

For questions regarding this privacy policy, please contact the developer through the project's GitHub repository.
